# ShadowVault

A text-based dungeon crawler built in C#.

## About

ShadowVault is an interactive console game where you navigate through dungeon rooms, collect items, and fight monsters. The game is built around core object-oriented design — every entity in the dungeon is modeled using class hierarchies, interfaces, and polymorphic behavior.

## Features

- Explore procedurally structured dungeon rooms
- Pick up and use items with different effects
- Fight multiple monster types with varied attack patterns
- Turn-based combat system
- Inventory management

## Tech

- C# / .NET
- Console Application

## Getting Started

```bash
git clone https://github.com/NandanDevHub/ShadowVault.git
cd ShadowVault
dotnet run
```
